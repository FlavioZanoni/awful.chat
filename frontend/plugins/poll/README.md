# Poll

Vote on options and watch live tallies. One vote per person, the LAST vote
counts (changing your vote works), voters and their choices are shown by
name - rooms are small, ballots are open.

## Usage

```
/poll Which map tonight? Dust2, Inferno, Mirage
```

Everything before the `?` is the question; options are comma separated,
minimum two. Your chosen option is marked and stays changeable.

## Install

Built in: ships with every awful.chat instance, nothing to configure.
Toggle per user in Settings > Plugins.

## Instance requirements

None.
